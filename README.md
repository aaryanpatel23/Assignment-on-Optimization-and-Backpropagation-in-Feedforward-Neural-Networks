# Backpropagation and Optimizer Comparison

Deep Learning (2087101) practical project.

## Contents
- `backprop_optimizer_comparison.ipynb`: NumPy backpropagation from scratch plus PyTorch comparison of SGD with momentum and Adam.
- `backprop_from_scratch.py`: Standalone script for Question 1.
- `report.pdf`: Short typed report with methodology, equations, and result fields.

## Run
Recommended: Google Colab. Upload the notebook and select Runtime → Run all.
Dependencies: `numpy`, `matplotlib`, `scikit-learn`, `torch`.

If running locally, install dependencies with:
`pip install numpy matplotlib scikit-learn torch`

The notebook prints the measured final losses, test losses, accuracy, elapsed time, and convergence threshold epochs. Copy the results from your run into the report. Training time varies by computer, so use your own output logs.
